# 주식회사 유엔아이 홈페이지 시안

디스플레이 · 반도체 장비용 프로파일 프레임 · 펜스 제작 회사 유엔아이(UNI)의 소개 랜딩 1페이지 시안. `main` 브랜치에 푸시하면 GitHub Pages로 자동 배포된다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 전체(반응형, 다크 · 라이트 자동). 첫 화면 → 협력사 · 인증 띠 → 사업 → 공정(스크롤하면 프레임이 조립되는 도식) → 제작 사례(설계 ↔ 사용 장면 비교 슬라이더) → 신공장(D-day · 연혁) → 인증서 → 문의 · 지도 |
| `img/` | 공장 사진, 인증서, 제작 사례 이미지(사용 장면은 설계 데이터와 실물을 바탕으로 만든 연출 이미지) |
| `robots.txt` | 시안 기간에는 검색 노출 차단. 정식 오픈 때 `index.html`의 `noindex` 메타와 함께 푼다 |

## 미리 보기

```bash
python -I -m http.server 5088 --bind 127.0.0.1 --directory .
```

## 남은 일

- 실제 제작품 사진(사업 4칸 배경, 지금은 무늬)
- 공정 4단계 문구 확인
- 로고(지금은 임시 UNI 표식)
- 문의 폼 실제 전송(지금은 입력 검사까지만), 도메인 연결, 검색 등록
